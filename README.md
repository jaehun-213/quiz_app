# IT 기술 퀴즈 웹 앱

## 프로젝트 개요
Firebase(Auth, Firestore)와 Vanilla JavaScript를 사용하여 구축된 반응형 SPA(Single Page Application) 퀴즈 웹 애플리케이션입니다.

## 주요 기능
- [ ] 사용자 회원가입/로그인 (Firebase Authentication)
- [ ] IT 기술 퀴즈 풀이
- [ ] 실시간 랭킹 시스템 (Cloud Firestore)
- [ ] 반응형 디자인 (모바일/데스크톱 지원)

## 기술 스택
- **Frontend**: Vanilla JavaScript (ES6+), HTML5, CSS3
- **Backend**: Firebase Authentication, Cloud Firestore
- **스타일링**: CSS Flexbox/Grid, 반응형 디자인
- **아키텍처**: SPA (Single Page Application)

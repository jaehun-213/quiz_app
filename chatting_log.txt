질문1
프로젝트 목표: HTML, CSS, JavaScript(바닐라 JS)만을 사용하여 다양한 유형의 퀴즈(객관식, 빈칸 채우기, 서술형)를 풀 수 있는 인터랙티브 웹 애플리케이션을 제작합니다.

핵심 기능:

다양한 문제 유형: 객관식, 빈칸 채우기, 서술형 문제를 모두 지원해야 합니다.

동적 렌더링: 문제 유형에 따라 질문과 답변 UI(라디오 버튼, 텍스트 입력, 텍스트 영역)가 동적으로 변경되어야 합니다.

데이터 분리: 문제 데이터는 JavaScript 코드 내의 JSON 형식 배열로 관리하여, 나중에 문제를 쉽게 추가/수정할 수 있어야 합니다.

채점 시스템:

객관식/빈칸 채우기: 자동 채점

서술형: 자동 채점이 불가능하므로, 사용자가 답을 제출하면 **'모범 답안'**을 보여주어 스스로 비교(Self-Grading)할 수 있게 합니다.

상태 관리: 현재 문제 번호, 사용자 점수를 추적하고 퀴즈가 끝나면 최종 점수를 보여줍니다.

📂 요청 파일 구조
총 3개의 파일을 생성해 주세요:

index.html (기본 HTML 구조)

style.css (기본 스타일링)

script.js (퀴즈 로직 및 문제 데이터)

📜 파일별 상세 요구사항
1. index.html
퀴즈 앱의 기본 골격을 포함해야 합니다.

<header>: "IT 지식 퀴즈" 같은 제목(h1)을 포함합니다.

<main id="quiz-container">:

<div id="progress-info">: "문제 1 / 10", "점수: 0" 등을 표시할 영역입니다.

<div id="question-text">: 현재 문제의 질문이 표시될 영역입니다.

<div id="answer-area">: 문제 유형에 따라 동적으로 (라디오 버튼/입력창/텍스트 영역이) 삽입될 영역입니다.

<div id="feedback-area">: 정답/오답 또는 서술형 모범 답안이 표시될 영역입니다.

<button id="submit-btn">: '제출' 또는 '다음' 버튼의 역할을 할 버튼입니다.

2. style.css
전반적으로 깔끔하고 모던한 디자인을 적용해 주세요.

quiz-container를 화면 중앙에 보기 좋게 배치해 주세요.

문제 텍스트(question-text)는 굵고 명확하게 보이도록 합니다.

코딩 퀴즈를 위해 <code> 또는 <pre> 태그를 사용했을 때를 대비해, 코드 블록 스타일을 보기 좋게 디자인해 주세요 (예: 회색 배경, 고정폭 글꼴).

'정답'일 때는 녹색, '오답'일 때는 빨간색으로 피드백을 명확히 보여주세요.

이 파일이 가장 중요합니다.

4. 퀴즈 로직 함수

function loadQuiz():

currentQuestionIndex를 기반으로 questions 배열에서 현재 문제 데이터를 가져옵니다.

question-text 영역에 질문을 표시합니다.

answer-area를 초기화합니다.

문제의 type을 확인합니다.

(동적 렌더링):

type이 'multiple-choice'면: options 배열을 순회하며 라디오 버튼(<input type="radio">)과 라벨을 생성하여 answer-area에 삽입합니다.

type이 'fill-in-the-blank'면: 텍스트 입력창(<input type="text">)을 answer-area에 삽입합니다.

type이 'short-answer'면: 여러 줄 입력창(<textarea>)을 answer-area에 삽입합니다.

feedback-area를 비우고 submit-btn의 텍스트를 '제출'로 설정합니다.

function handleSubmit():

submit-btn을 클릭했을 때 호출됩니다.

feedback-area가 비어있다면 (즉, '제출' 단계라면):

현재 문제의 type을 확인합니다.

(채점 로직):

'multiple-choice': 선택된 라디오 버튼의 값이 answer와 일치하는지 확인합니다.

'fill-in-the-blank': 입력된 텍스트 값(공백 제거 .trim() 및/또는 .toLowerCase() 처리)이 answer와 일치하는지 확인합니다.

'short-answer': 채점하지 않습니다.

(피드백):

객관식/빈칸: '정답입니다!' 또는 '오답입니다. 정답: [정답]'을 feedback-area에 표시합니다. 정답 시 userScore 증가.

서술형: modelAnswer를 feedback-area에 표시합니다 (예: "모범 답안: [modelAnswer]").

submit-btn의 텍스트를 '다음 문제'로 변경합니다.

feedback-area에 내용이 있다면 (즉, '다음 문제' 단계라면):

currentQuestionIndex를 1 증가시킵니다.

currentQuestionIndex가 questions.length보다 작은지 확인합니다.

작다면: loadQuiz()를 다시 호출하여 다음 문제를 로드합니다.

크거나 같다면: showResults() 함수를 호출합니다.

function showResults():

quiz-container의 내용을 모두 지웁니다.

"퀴즈 완료! 당신의 점수는 [총 문제 수]점 만점에 [userScore]점입니다." 같은 최종 결과 메시지를 표시합니다.

5. 이벤트 리스너

document.addEventListener('DOMContentLoaded', loadQuiz); (페이지 로드 시 첫 문제 시작)

submitBtn.addEventListener('click', handleSubmit); (버튼 클릭 시 로직 실행)
